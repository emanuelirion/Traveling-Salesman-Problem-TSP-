# data/

Instâncias de entrada. Cada instância é uma subpasta com dois arquivos CSV (formato definido na seção 2 de [`../docs/MODELAGEM.md`](../docs/MODELAGEM.md)):

- `cidades.csv`: `id,nome,x_km,y_km` (id 0 = sede);
- `arestas.csv`: `origem,destino,distancia_km,pedagio_rs`, uma linha por aresta, com o grafo completo.

As instâncias serão sintéticas (geração descrita na seção 8 da modelagem). **Ainda não geradas.**
